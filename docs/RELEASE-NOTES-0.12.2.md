# Achievement Relay v0.12.2

## Clearer Home game status

The Home card now says **Now playing** only when Steam detects an active game. When it displays a saved Xbox snapshot, it says **Last observed** and makes clear that this is saved progress, not live presence. With neither, it says **No active game**.

Saved Xbox progress and empty states no longer show an active-session unlock count. Achievement monitoring, Discord delivery, settings and history are unchanged. The Steam observer reliability fix from v0.12.1 is included.

The Signal Strip overlay, Collector Card showcase, Xbox PC Game Pass labels and optional encrypted account sync are preserved.

## Installation

Use **AchievementRelay_Setup.exe** or Relay’s update prompt. Signed **AchievementRelay_0.12.2.0_x64.msix** and ARM64 packages and the signed updater manifest are included. The minimum supported update version remains v0.4.0.
