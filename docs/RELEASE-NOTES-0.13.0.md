# Achievement Relay v0.13.0

## Artwork-first Discord posts

Steam and Xbox unlocks now arrive as large 1200×750 Collector Card showcase posters: sharp game artwork, bold ivory achievement titles, twin red bars and a compact player/rarity footer. Xbox cards retain gamerscore and the platform label, including Xbox PC Game Pass where supported by provider evidence.

Posts no longer repeat all of the image details above the card. Accessible attachment text retains achievement, player, platform, rarity and gamerscore details, with a real Get Achievement Relay link below the image. Unlock timestamps remain available; detected timestamps are labelled when no platform time exists.

Artwork comes from the existing provider sources. Games without suitable landscape artwork receive the branded fallback; tiny icons are never stretched across the poster. Unknown rarity stays unknown. Verified completion gets a dedicated header. Compact posts and safe standard-embed fallback remain available.

The Signal Strip overlay, optional encrypted sync, Steam observer reliability fix and clearer Home game status remain included. Rendering runs locally without a paid image-generation service.

## Installation

Use **AchievementRelay_Setup.exe** or Relay’s update prompt. Signed **AchievementRelay_0.13.0.0_x64.msix** and ARM64 packages and the signed updater manifest are included. The minimum supported update version remains v0.4.0.
