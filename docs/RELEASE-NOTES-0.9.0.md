# Achievement Relay v0.9.0

## Your achievement companion

Open **Companion** from the Redline sidebar for a persistent gallery, session recaps, per-game preferences and live connection health. The gallery keeps the latest 300 live unlocks observed on this PC, including delivery status; it does not import or repost historical unlocks. Search by game or achievement and filter platform, date, rarity or pending delivery. Select an entry for readable details and official provider artwork.

Replay a Signal Strip overlay locally, preview the Discord card, or explicitly retry pending delivery through the existing delivery checks. Delivered and filtered entries cannot be manually reposted through Retry.

Sessions group unlocks separated by less than 30 minutes and show game count, Gamerscore and the rarest recorded unlock. Sharing a recap to Discord is an explicit action. The final eligible live unlock on Steam or Xbox can carry a verified 100% completion showcase with the rarest unlock in this PC's retained game history. Missing totals are not guessed; completion proof is saved before delivery and survives retries.

## Presentation controls

Choose an overlay screen, drag its position or use keyboard-accessible corner presets, select 75–150% sizing and a 3–12 second hold. Gold and Platinum sounds are distinct; rare unlocks receive a stronger artwork pulse. Choose the Collector Card showcase or compact Discord presentation. Per-game preferences can mute sound, hide the overlay or restrict celebrations to rare unlocks. Global animation, sound and high-contrast controls remain in force.

## Reliability and updates

The health view shows source observations, confirmed Discord delivery, errors, update progress and release notes. A setup checklist links to the existing connection checks and offers a local sample unlock.

Optional cross-PC coordination uses an existing writable Windows network folder shared by both PCs with the same webhook. Exclusive file claims serialize delivery. Cloud-synced folders are not supported. Share unavailability delays posting; an interrupted send with an unknown outcome is held for investigation instead of being automatically duplicated. This mode prioritizes avoiding duplicate posts and can require manual investigation after a crash. Both PCs must enable it.

Existing state, connections, silent historical baselines, Xbox PC Game Pass labels and the v0.4.0 update floor are preserved. No extra service subscription is introduced.

## Installation

Use **AchievementRelay_Setup.exe**. The release also contains **AchievementRelay_0.9.0.0_x64.msix**, ARM64 and manual installer packages, publisher certificate and signed update manifest.
