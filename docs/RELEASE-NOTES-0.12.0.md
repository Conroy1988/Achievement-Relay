# Achievement Relay v0.12.0

## Clearer everyday controls

Home now puts your next action first and opens your achievements when Relay is ready. Navigation and compact layouts are easier to use, with searchable activity and a direct Account entry.

Settings has an always-visible Save/Discard footer, section shortcuts and Ctrl+S. Unsaved edits are protected during sync and connection changes, and a failed save keeps your work available to retry.

## Friendlier account setup and Companion

Optional Discord login guides you through sign-in, recovery-key backup and pairing. Account identity, last-sync status, cancellation and recovery guidance are clearer. Account sync remains an optional beta on Supabase Free.

Companion adds library search and sorting, clearer sound previews, protected per-game edits, readable long titles, keyboard focus outlines and named lists. Imported or synced achievements are labelled as history, stay out of local session recaps and cannot invoke delivery recovery.

The Signal Strip overlay, Collector Card showcase, Xbox PC Game Pass labels and v0.4.0 minimum-supported update baseline are preserved. Historical imports do not become new Discord posts.

## Install or update

Use **AchievementRelay_Setup.exe**, or the app's update prompt. The release includes a signed update manifest, the existing publisher certificate, AchievementRelay_0.12.0.0_x64.msix, an ARM64 package and a fallback installer ZIP.

Your saved configuration and history are retained by the existing update flow. Keep your account recovery key backed up before moving to another PC.

## Validation and remaining acceptance

The UI changes passed 79 core checks, 22 app checks, Windows packaging and security scans. Isolated native acceptance covers 300 achievements, 100 games, failed saves and retry, filtering, historical labels and real overlay placement/size/duration.

Physical two-PC, monitor/audio, high-contrast and screen-reader walkthroughs, and upgrade/uninstall acceptance on a separate Windows installation remain unverified. These are documented in the whole-app review; automated success is not a claim that those live scenarios have been tested.
