# Achievement Relay v0.13.1

## A more readable achievement footer

Player names and Xbox gamerscore are now 50% larger on Collector Card showcase posters. Achievement icons and rarity medallions are larger too. The rarity percentage has its own bold line, with “of Steam players” or “of players” below it, so the footer stays readable when Discord scales the image down.

The artwork, achievement title, card dimensions and red branding from v0.13.0 remain unchanged. Unknown rarity keeps its honest Unranked label. Xbox PC Game Pass labels and the Signal Strip overlay are preserved.

## Installation

Use **AchievementRelay_Setup.exe** or Relay’s update prompt. Signed **AchievementRelay_0.13.1.0_x64.msix** and ARM64 packages and the signed updater manifest are included. The minimum supported update version remains v0.4.0.
