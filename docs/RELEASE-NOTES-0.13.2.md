# Achievement Relay v0.13.2

## Remember the game you just played

Home now retains the last played game after Steam closes and across Relay restarts. Steam activity is saved as soon as a game is detected, even before achievement data arrives. Xbox background progress refreshes cannot replace it with an older title: Xbox uses its reported last-played timestamp.

Only an active Steam game is labelled Now Playing. Saved activity is labelled Last Played. Activity tracking stays local and separate from achievement delivery, so it cannot resend old unlocks.

The Collector Card showcase, Xbox PC Game Pass labels, and Signal Strip overlay are preserved.

## Installation

Use AchievementRelay_Setup.exe or Relay's update prompt. Signed AchievementRelay_0.13.2.0_x64.msix and ARM64 packages are included. Minimum supported update version remains v0.4.0.
